# Keystrokes

## Vim / Neovim

- `,dn` toggle line numbers
- `,dR` reload config
- `,dov` / `,doV` open init.lua (split / tab)
- `,dot` open tmux.conf
- `,dobb` open shell stub
- `,dt` open Oil (file browser)
- `<C-p>` / `<leader>ff` Telescope find files
- `<leader>fg` live grep
- `gd` go to definition (LSP)
- `K` hover
- `<leader>rn` rename

## Tmux

Prefix is `Ctrl-a`. Plugins: tpm, sensible, pain-control, yank, sessionist, resurrect, continuum.

### Essentials

- `prefix + I` install plugins
- `prefix + U` update plugins
- `prefix + |` / `prefix + -` split panes
- `prefix + h/j/k/l` navigate panes
- `prefix + Ctrl-s` / `prefix + Ctrl-r` save / restore (resurrect)
- `Escape` enter copy-mode; `v` / `y` select / yank

See also the longer historical list in git history under the old `keystrokes.md`.
